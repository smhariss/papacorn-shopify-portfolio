# PapaCorn homepage font provenance

Downloaded 10 October 2026. Both font files are unmodified and bundled with their respective SIL Open Font License 1.1 notices.

- `Bounded-Medium.otf`: Bounded Medium, normal style, weight 500. Official author repository: https://github.com/churkinvlad/Bounded . Direct source: https://raw.githubusercontent.com/churkinvlad/Bounded/main/OTF/Bounded-Medium.otf . License: `Bounded-OFL.txt`, from https://raw.githubusercontent.com/churkinvlad/Bounded/main/OFL.txt . Used as `PapaCornBody` in CSS.
- `SpicyRice-Regular.ttf`: Spicy Rice Regular, normal style, weight 400. Official Google Fonts distribution: https://github.com/google/fonts/tree/main/ofl/spicyrice . Direct source: https://raw.githubusercontent.com/google/fonts/main/ofl/spicyrice/SpicyRice-Regular.ttf . License: `SpicyRice-OFL.txt`, from https://raw.githubusercontent.com/google/fonts/main/ofl/spicyrice/OFL.txt . Used as `PapaCornDisplay` in CSS.

Spicy Rice is an openly licensed upright display alternative chosen for the reference's groovy character. It is not the reference's Soledago typeface and does not reproduce its exact glyphs. Bounded Medium matches the reference's named body/navigation family. Synthetic bold and italic are disabled; display text uses 400 and body/navigation text uses 500.

Keep the license notices when distributing these font assets. When copying the CSS into Shopify, replace the relative font URLs with the corresponding Liquid `asset_url` paths.
